# Python-Small-Practics-Projects
# Python Small Practical Projects

A collection of small and beginner-friendly Python projects created to practice and strengthen fundamental programming concepts. These projects focus on problem-solving, logic building, user input, data handling, loops, conditional statements, functions, and basic Python programming.

## Projects Included

### 1. Expense Tracker App

A simple command-line application for recording and managing daily expenses.

**Features:**

* Add expenses
* Store expense details
* Calculate total expenses
* Display recorded expenses
* Practice lists, loops, and user input

**Concepts Used:**
`Lists` `Loops` `Conditional Statements` `Functions` `User Input` `Arithmetic Operations`

---

### 2. General Knowledge Quiz

A simple interactive quiz application that asks users general knowledge questions and calculates their score.

**Features:**

* Multiple questions
* User input
* Automatic answer checking
* Score calculation
* Final score display

**Concepts Used:**
`Variables` `Lists` `Loops` `Conditional Statements` `User Input` `Score Calculation`

---

### 3. Hangman Game

A command-line word guessing game where the player attempts to guess a hidden word within a limited number of attempts.

**Features:**

* Random word selection
* Letter guessing
* Tracks guessed letters
* Displays game progress
* Win and lose conditions

**Concepts Used:**
`Strings` `Lists` `Loops` `Conditional Statements` `Random Module` `User Input`

---

### 4. Random Password Generator

A Python program that generates random passwords using a combination of characters.

**Features:**

* Generates random passwords
* Uses letters and numbers
* Customizable password length
* Random character selection

**Concepts Used:**
`Strings` `Random Module` `Loops` `User Input` `String Manipulation`

---

### 5. Stock Portfolio Tracker

A simple application for tracking stock holdings and calculating the approximate value of a portfolio based on stock prices.

**Features:**

* Add stock information
* Store stock quantities and prices
* Calculate individual stock values
* Calculate total portfolio value

**Concepts Used:**
`Dictionaries` `Lists` `Loops` `Conditional Statements` `Functions` `Arithmetic Operations`

> **Note:** This is an educational project and does not provide real-time financial or investment advice.

---

### 6. To-Do List App

A simple command-line task management application that allows users to create and manage a list of tasks.

**Features:**

* Add new tasks
* View tasks
* Remove tasks
* Manage a task list
* Simple interactive menu

**Concepts Used:**
`Lists` `Loops` `Conditional Statements` `Functions` `User Input` `enumerate()`

---

## How to Run

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the Project Folder

```bash
cd Python-Small-Practical-Projects
```

### 3. Run a Project

For example:

```bash
python expense_tracker.py
```

or

```bash
python hangman.py
```

The exact command may vary depending on the location and filename of each project.
